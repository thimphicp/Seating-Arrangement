# 교실 자리 배치 · 청소 역할

학생 자리 배치, 청소 구역 배정, 청소 점검을 관리하는 프로그램입니다.

## 실행

Node.js 24 환경에서 실행할 수 있습니다. 별도 npm 패키지는 필요하지 않습니다.

```sh
node server.js
```

Windows에서는 기본 브라우저가 자동으로 열립니다. 직접 접속할 때는 터미널에 표시되는 주소(기본값 `http://localhost:7315`)를 사용하세요. 터미널을 닫으면 서버가 종료됩니다.

## 화면

- `index.html`: 학생 명단과 자리 배치
- `cleaning.html`: 청소 구역과 담당자 배정
- `check.html`: 청소 점검
- `recover.html`: 브라우저에 남은 저장 내용을 확인하고 복구

## 저장

서버로 실행하면 데이터는 `data/data.sqlite`에 저장됩니다. 프로그램이 생성하는 데이터와 백업은 Git에서 제외합니다. 여러 창에서 동시에 수정하면 충돌한 창의 저장을 멈추고 변경 내용을 내보낼 수 있습니다.

HTML 파일을 직접 여는 방식은 서버 실행과 저장 방식이 다릅니다. 전체 기능을 사용하려면 서버로 실행하세요.

## 웹 배포

현재 버전은 내 컴퓨터에서 실행하는 로컬 서버를 사용합니다. GitHub에 코드를 업로드하는 것만으로 온라인 서비스가 실행되지는 않습니다. GitHub Pages와 같은 정적 호스팅에서는 현재의 SQLite 저장 API를 실행할 수 없습니다.
